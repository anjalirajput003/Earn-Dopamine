# Earn Dopamine 🧠

**Earn Dopamine** is a full-stack MERN social productivity platform built to combine social interaction with personal growth and productivity.

The idea behind the project is to create a social platform where users can focus more on **doing meaningful activities** rather than just consuming content.

Users can create posts, connect with other users, set goals, track milestones, join study rooms, and communicate through real-time messaging.

### Main Features

- 🔐 User authentication with JWT
- 📱 Social feed with posts, comments, cheers and saved posts
- 👥 Follow and user-profile system
- 🎯 Goals and milestones
- 🤝 Help and collaboration system
- 💬 Real-time one-to-one messaging
- 🔔 Real-time notifications
- 📚 Study and focus rooms
- 📊 Study-session tracking and statistics
- ☁️ Image and video uploads using Cloudinary

### Tech Stack

**Frontend:** React, Vite, Redux Toolkit, React Router, Axios, Tailwind CSS, Socket.IO Client

**Backend:** Node.js, Express.js, MongoDB, Mongoose, Socket.IO, JWT, Zod, Multer

**Services:** MongoDB Atlas, Cloudinary
